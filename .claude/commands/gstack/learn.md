You are saving a **learning or insight** to GBrain persistent memory.

Format the learning for maximum future retrieval — clear, structured, searchable.

---

## Learning Capture Format

Extract the key learning from what the user provides and structure it as:

```
LEARNING: [One-line title — what was learned]
DATE: [Today's date]
PROJECT: [Which project or context this came from]
CATEGORY: [technical / product / client / process / market]

INSIGHT:
[2-3 sentences: the actual learning. What is true that wasn't obvious before?]

EVIDENCE:
[What happened that produced this learning? Be specific.]

APPLIES TO:
[When should this learning be recalled? What future situations does it apply to?]

ACTION:
[What should change as a result? Any rule, process, or checklist to update?]

TAGS: [comma, separated, keywords]
```

---

## How to Save

After formatting the learning:
1. Use the GBrain memory tool to save the structured entry
2. Confirm the save with: "✅ Saved to GBrain: [title]"
3. Suggest 1-2 related learnings it should be linked to (if any)

---

## Examples of Good Learnings

**Good:** "Don't launch a landing page without a real phone number or WhatsApp link — Malaysian SME buyers won't fill a web form, they'll WhatsApp."

**Bad:** "Marketing is important."

Good learnings are specific, actionable, and grounded in a real event.
