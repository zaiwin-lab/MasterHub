Clone families — your efficiency engine

The DBKU Green Kampung win was a reskin of the SEB Sungai Revive template: same architecture, new content, a fraction of the effort. That's the pattern to industrialise. Build one strong template per family, then sell reskins to each agency/client.

How to read verdicts. Ship = near done, finish & charge. Recycle = proven template, clone for the next client (highest margin). Build = worth completing, but only against a paying client. Hold = demo only, wait for real demand. Park = low value, don't invest.
